วิธีสร้าง Portable EXE ผ่าน GitHub Actions
==========================================

1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน Source นี้เข้า Repository ใหม่หรือ Repository ที่ต้องการ
   ต้องเห็นโฟลเดอร์ .github/workflows/build-windows-exe.yml
2. เปิดหน้า Repository แล้วเลือกแท็บ Actions
3. เลือก Build Windows Portable EXE ทางด้านซ้าย
4. กด Run workflow แล้วกดปุ่ม Run workflow สีเขียว
5. รอจนงานแสดงเครื่องหมายถูกสีเขียว
6. เปิดผลการรัน แล้วดาวน์โหลด Artifact:
   Delivery-Order-QR-Generator-Windows-Portable
7. แตก ZIP ทั้งชุด แล้วเปิด Delivery_Order_QR_Generator.exe

เครื่องผู้ใช้งานไม่ต้องติดตั้ง Python และไม่ต้องติดตั้ง Tesseract OCR
ห้ามย้ายเฉพาะไฟล์ EXE ออกจากโฟลเดอร์ เพราะโปรแกรมต้องใช้โฟลเดอร์ tesseract ที่อยู่ข้างกัน
